# Conversor de Moedas: Real ↔ Dólar

Programa simples que converte valores entre **Real (BRL)** e **Dólar (USD)**, com base em uma cotação informada pelo usuário.

Disponível em duas versões:
- **Portugol** (`conversorMoeda.por`) — feito para rodar no Portugol Studio.
- **Python** (`conversor_moeda.py`) — versão equivalente para rodar em qualquer ambiente com Python 3.

## Funcionalidades

- Conversão de Real para Dólar
- Conversão de Dólar para Real
- Validação de opção inválida
- Validação de cotação e valores negativos

## Exemplo de execução

```
=== Conversor de Moedas: Real <-> Dólar ===

Digite 1 para converter Real -> Dólar
Digite 2 para converter Dólar -> Real
Escolha a opção: 1

Qual a cotação do Dólar hoje (em R$): 5.40
Digite quantos Reais você deseja converter: 100

100.0 em Reais equivale a 18.52 em Dólares.
```
